# Customer Churn Analytics — Data Science Internship (Week 5 Final Project)

End-to-end churn analysis: data cleaning → EDA → predictive modelling → strategic recommendations → business-impact estimate.

**Final report:** [`reports/Week5_Final_Project_Report.docx`](reports/Week5_Final_Project_Report.docx)

## Key results
| Metric | Value |
|---|---|
| Customers analysed | 5,000 (37.8% churned) |
| Best model | Logistic Regression, ROC-AUC 0.83 |
| Top-decile lift | 2.2x |
| Churners captured in top 20% risk band | 41.5% |
| Top drivers | Contract type, tenure, monthly charges, payment method |

## Repository structure
| File / Folder | Description |
|---|---|
| `README.md` | Project overview, results and run instructions |
| `requirements.txt` | Python dependencies |
| `run_all.sh` | Runs the whole pipeline in order |
| `build_report.js` | Node script that assembles the Word report from figures and metrics |
| `.gitignore` | Files git should ignore |
| `data/customer_churn.csv` | Raw (synthetic) dataset, 5,000 rows x 12 columns |
| `data/customer_churn_clean.csv` | Cleaned dataset (missing `total_charges` imputed) |
| `src/generate_data.py` | Generates the reproducible dataset (seed 42) |
| `src/eda.py` | Cleaning + exploratory analysis; saves Figures 1-5 |
| `src/modeling.py` | Pipeline, 3 models, evaluation, importance, lift; saves Figures 6-9 and metrics |
| `images/fig1…fig9*.png` | All charts used in the report |
| `outputs/metrics.json` | Final model metrics and business-case inputs |
| `outputs/model_comparison.csv` | Model comparison table |
| `outputs/feature_importance.csv` | Permutation importance scores |
| `outputs/churn_by_*.csv` | Segment churn rates (contract, payment, internet) |
| `reports/Week5_Final_Project_Report.docx` | Final comprehensive report |

## How to run
```bash
pip install -r requirements.txt
bash run_all.sh
npm install docx && node build_report.js   # optional: rebuild the report
```

## Using your own data
Replace `data/customer_churn.csv` with your dataset using the same column names (target column `churn`), then rerun `run_all.sh`.

## Note
The included dataset is synthetic and generated by `src/generate_data.py` so results are fully reproducible.
